# Ramify

Base con Next.js, React, Tailwind CSS y TypeScript.

## Desarrollo

Usa exclusivamente pnpm (versión indicada en `package.json`).

```bash
pnpm install
pnpm dev
```

Abre http://localhost:3000. La página inicial está en `src/app/page.tsx`.

## Comandos

```bash
pnpm build
pnpm start
pnpm lint
```
